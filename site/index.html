Part 1 · hard rules

Two rules a script can check.

RULE 1

Subject first.

No sentence opens with an adverbial. That covers prepositional phrases, infinitive purpose phrases, Because, When, and If clauses, participial openers, and -ly adverbs. Move the phrase after the verb.

In parallel, I ran an ablation.
I ran an ablation in parallel.

Fine as openers: Furthermore, However, Therefore, Thus, Also, Then, Still, Finally, Meanwhile, Instead.

RULE 2

No em dashes.

Never write the long dash, or a spaced hyphen standing in for one. Reach for a period, a comma, a colon, or parentheses. An en dash inside a number range is fine.

The test passed — barely.
The test passed, barely.

Em dashes were flagged in nine of thirteen blind-test pairs.

Part 2 · measured habits

Habits that fix the way AI writes.

The skill tells the agent what to write, not only what to avoid, because a rule against something leaves room to argue. These habits guide the draft as the agent writes it. The script does not check them.

LENGTH

Vary the sentences.

Let a long sentence carry the reasoning. Use a short one only where it earns the stress.

COMPLETENESS

Give the full account.

A PR body or email gets what changed, why, the caveats, and the next step. Readers preferred the thorough version every time.

STRUCTURE

Match the register.

Headings and lists for reference material. Plain paragraphs for a chat message, an email, or a story.

SPECIFICS

Lead with the vivid fact.

Slide titles state the conclusion, not the topic. No Challenge, Solution, Results template.

FICTION

Pick details you have not used.

A model left to itself writes the same story: a lighthouse keeper, the same few names, the same opening. The skill steers it toward fresh details and a story that builds to a turn.

CLOSINGS

End on a concrete line.

A landing page ends on its best fact, such as “Setup takes one command.” It skips “Contact us today to learn more!”

The filter

Flags problems for the agent to fix

The script needs only Python 3. It skips fenced and inline code, prints each violation with its line, and exits 0 when the text is clean. Nothing runs on its own, because the plugin installs no hooks.

Not built to beat detectors

Prose Craft does not try to pass AI detection. The goal is prose that reads well to a person, and detector scores do not measure that.

No facts added

Prose Craft changes how a draft is written, not what it says. It uses only the facts you supply and adds no dates, numbers, people or claims of its own.

Other harnesses

Works in any harness.

That includes Codex and OpenCode. Prose Craft is a standard SKILL.md folder, so any harness that reads Agent Skills can load it. Drop prose-craft into its skills directory, then ask for it by name or let the description trigger it. The filter is plain Python 3 and takes any agent command.

# Codex: built-in skill installer
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py --repo nhangen/prose-craft --path skills/prose-craft
# OpenCode: clone, then copy the folder
git clone https://github.com/nhangen/prose-craft
cp -R prose-craft/skills/prose-craft ~/.config/opencode/skills/
Then
  • Ask the agent to write with prose-craft, or let it load on its own when you draft prose.
  • Run the filter from inside the installed skill folder: python3 scripts/prose-filter.py check draft.md.
  • Pass any agent to run --agent to loop until clean.
